# OpenClaw LINE Setup

คู่มือภาษาไทยสำหรับเชื่อมต่อ OpenClaw กับ LINE Messaging API มีไฟล์คู่มือ LINE_SETUP_THAI.md, LINE_SETUP_THAI_COMPLETE.md และ GATEWAY_TROUBLESHOOTING_THAI.md พร้อมตัวอย่าง config (.json5) สำหรับ ~/.openclaw/openclaw.json ก่อนเริ่มให้รัน bash setup-checker.sh เพื่อตรวจระบบ แล้วทำตามคู่มือ เริ่มจากติดตั้ง LINE plugin ด้วย openclaw plugins install @openclaw/line
